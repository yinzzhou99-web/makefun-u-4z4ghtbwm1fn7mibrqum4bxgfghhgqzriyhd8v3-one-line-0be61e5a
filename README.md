**One Line, One Laugh** — a single funny line, readable in one breath. The Wi-Fi and I are growing apart.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (standard library only, no network) writes the line to `/output/entry.txt` and checks it against the gate (1–140 chars).
